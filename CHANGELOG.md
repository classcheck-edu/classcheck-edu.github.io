# Changelog

## 1.0.0 — First public release / Bản phát hành công khai đầu tiên

**EN**
- Shared web app for lecturers and students: GPS attendance, rotating PIN/QR, per-class attendance rules, roster sync.
- Each lecturer runs on their own Google Sheet + Apps Script backend (`code1.0.0.text`, `sync.txt`); the web app holds no lecturer-specific URL, name or ID.
- Based on CCS 3.9.2.

**VI**
- Web dùng chung cho giảng viên và sinh viên: điểm danh GPS, PIN/QR xoay vòng, quy tắc điểm danh theo lớp, đồng bộ danh sách.
- Mỗi giảng viên chạy trên Google Sheet + backend Apps Script riêng (`code1.0.0.text`, `sync.txt`); web không chứa URL, tên hay ID riêng của giảng viên nào.
- Dựa trên CCS 3.9.2.
