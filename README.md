# ClassCheck — Hệ Thống Điểm Danh Định Vị (CCS)

Giao diện Web trung lập dùng chung cho Giảng viên và Sinh viên tại **[https://classcheck-edu.github.io/](https://classcheck-edu.github.io/)**.

- **Sinh viên:** Quét mã QR Đăng ký lớp học của Giảng viên ở buổi đầu học kỳ để liên kết thiết bị và điểm danh GPS 1 chạm.
- **Giảng viên:** Mỗi Giảng viên vận hành trên bản sao Google Sheet độc lập (kết nối qua đường dẫn Web App tại ô `B4` và `Master Key`).
